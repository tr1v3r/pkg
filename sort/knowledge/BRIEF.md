# sort 知识库（合并版五件套）

组件：泛型排序工具——单键 By 闭包 + 多键 MultiBy 字典序，适配标准库 sort.Sort。操作 []*T 指针切片。
更新日期：2026-10-12（刷新 @ d6b2b9c：功能零变化，5d88794 给 Len/Swap/Less 补 sort.Interface 实现注释）。证据等级：A=代码现状/可回查提交，C=推测。

## 流程

```text
【单键排序】(sort.go)
By[T](l, r *T) bool 闭包 → .Sort(items []*T)：包进 sorter[T] 走 sort.Sort
ReverseBy(by)：参数对调生成逆序闭包（组合而非反向遍历）

【多键排序】
MultiBy(less1, less2, ...).Sort(items)
Less 逻辑：逐个试 less（前 n-1 个）：less(l,r)→true；less(r,l)→false；相等→下一个键
           最后一个键直接返回其结果 —— 经典字典序短路
约束：sort.Sort 非稳定排序，相等元素相对次序不保证；By[T] 以 *T 比较，元素为指针
```

## 决策

- D-001 API 面向 []*T 指针切片（2026-10-12，A：f59633f，2024-01-15，从 []T 改为 []*T 的既成 breaking）。动机 (C)：推测为排序共享结构体时免值拷贝、且闭包直接拿 *T。重新评估：若生态迁移到 slices.SortFunc 风格值语义，需新 API 而非原地改。
- D-002 建在 sort.Interface 之上而非 slices.SortFunc：与标准库 sort 文档里的经典闭包示例同构（2026-10-12，A：代码现状；承自 stdlib 示例 (C) 推测）。影响：通用性好但放弃 pdqsort 内核与泛型内联优势。
- D-003 非稳定排序被静默接受：未提供稳定变体（2026-10-12，A：代码现状）。

## 验收案例

- S-001 单键与逆序：对若干 *T 按 By 升序 Sort 后断言有序；ReverseBy(by) 再排断言完全逆序（无重复元素时）。验证：逐对比较。
- S-002 多键短路：以 (姓名, 年龄) 双键排序含同名不同龄数据 → 姓名决定主序，同名内按年龄；仅当两键全等才任意序（不稳定）。验证：分组断言。
- S-003 边界：空切片与单元素切片 Sort 为 no-op 不 panic。验证：长度不变 + 无 panic。
- S-004 指针语义：排序后原切片内指针指向的对象未被修改/复制，仅指针位置重排。验证：比较对象字段与指针身份。
